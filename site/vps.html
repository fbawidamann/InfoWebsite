Aufbau des VPS

Erstellt mit draw.io

Erklärung

Hostinger

  • Server läuft als VPS bei Hostinger
  • Ubuntu-Image genutzt
  • Domain auch bei Hostinger eingerichtet und verwaltet

SSH

  • Änderung des Standard Ports 22 auf secret
  • Passwort-Anmeldung deaktiviert (Anmeldung nur mit private + public key möglich)
  • Nutzung von ufw-Firewall und fail2ban

Traefik

  • Läuft als Reverse Proxy in einem eigenen Docker-Container
  • Leitet eingehende Anfragen automatisch an die passenden Container weiter
  • Stellt TLS-Zertifikate über Let's Encrypt automatisch aus und erneuert sie

Docker

  • Webseiten, Traefik, Game-Server und der Hermes-KI-Agent laufen isoliert in eigenen Containern
  • Vereinfacht Wartung und Updates der einzelnen Anwendungen
  • Saubere Trennung der Dienste voneinander

Hermes-KI-Agent

  • KI kann Server steuern, Informationen geben, Dateien erstellen, bearbeiten und löschen
  • Nur erreichbar per direktem Aufruf und Telegram API
  • Nutzt Modell von Anthropic (Opus 5)

Zusätzliche Info

Dieses Projekt entstand nicht durch ein spezifisches Modul während meines Studiums. Jedoch wurde ich durch das Modul "Betriebssysteme" auf die Nutzung von linux basierten OS aufmerksam. Durch verschiedenste Youtube-Videos stieg mein Interesse daran auch einen eigenen Server zu haben, auf dem ich Dinge ausprobieren, und neues erlernen kann.
